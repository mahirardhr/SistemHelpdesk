# SihaloTI — Sistem Helpdesk TI

SihaloTI merupakan aplikasi helpdesk berbasis web yang dikembangkan sebagai proyek tugas akhir untuk mendukung pengelolaan pengaduan dan penanganan kendala TI di PTPN IV Regional III.

Repositori ini menyajikan dokumentasi portofolio proyek. Kode sumber dan data operasional tidak disertakan.

## Tujuan

Memusatkan pencatatan pengaduan, membantu pemantauan progres penanganan, serta mendukung evaluasi layanan TI melalui riwayat tiket dan penilaian pengguna.

## Fitur utama

- Pengajuan dan pengelolaan tiket pengaduan.
- Pemantauan status tiket: `open`, `in_progress`, dan `closed`.
- Pengaturan prioritas dan penanggung jawab (PIC).
- Pemantauan Service Level Agreement (SLA).
- Timeline penanganan tiket.
- Rating layanan.
- Knowledge base.
- Grafik dan ekspor laporan PDF serta Excel.

## Teknologi

| Komponen | Teknologi |
| --- | --- |
| Framework backend | Laravel 9 |
| Komponen interaktif | Livewire 2 |
| Bahasa backend | PHP |
| Database | MySQL |

## Pengembangan dan pengujian

Pengembangan dilakukan menggunakan metode Prototype dengan menyesuaikan sistem terhadap kebutuhan pengguna. Pengujian mencakup pengujian black box dan evaluasi usability menggunakan System Usability Scale (SUS).

## Kontribusi pengembang

Mahirah Ra’idah terlibat dalam analisis kebutuhan, pengembangan aplikasi, pengujian, dokumentasi, dan deployment sistem sebagai bagian dari proyek tugas akhir.
